Home Base Privacy Policy

Last updated October 23, 2026

Home Base is a personal desktop dashboard made by one developer for their own use. It is not offered to the public.

What Home Base accesses

When the person using Home Base signs in with Google, the app requests read-only access to:

  • Google Calendar, to show upcoming events and coursework due dates
  • Gmail, to show the sender and subject of unread messages in the Primary inbox
  • Google Drive file details (names, types and dates), to show recently opened files

Home Base never sends email, changes calendar events, or edits or deletes files.

Where data goes

Google data is fetched directly from Google to the signed-in person's own computer and is shown on screen. It is not uploaded to any server, and it is not sold, shared or used for advertising. The sign-in token and anything entered into the app (tasks, budget entries, trackers) are stored only on that computer.

Removing access

Access can be revoked at any time from Google Account → Third-party apps & services. Deleting the app's data folder removes everything it stored on the computer.

Google API Services User Data Policy

Home Base's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
